Demozoo API

Demozoo provides a JSON API at https://demozoo.org/api/v1/, giving full programmatic access to production, scener, party and BBS data. You can freely browse this data as a logged-in user. {% if api_keys_enforced %} To access the API from code, you will need to create an API key. {% else %} From 1st November 2026, anonymous access to the API will be disabled and you will need to create an API key to access the API from code. {% endif %}

It is recommended to pass the API key as an Authorization HTTP header:

Authorization: Api-Key 1234aBCd.yourkeyhere

Alternatively, it can be passed as a URL parameter api_key:

https://demozoo.org/api/v1/productions/?api_key=1234aBCd.yourkeyhere

Don't be a resource hog! If you're making repeated API requests, please leave a 1 second pause between them.

A public SQL dump of the whole database (minus sensitive information such as password hashes) is also available at https://data.demozoo.org/demozoo-export.sql.gz, updated nightly.
